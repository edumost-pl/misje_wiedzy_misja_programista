# MISJE WIEDZY

Interaktywna **seria książek edukacyjnych** dla dzieci 9–11 lat.

**Główny cel:** nauka czytania ze zrozumieniem.  
Technologia (np. Raspberry Pi 5) jest tematem opowiadań — nie kursem.

## Nawigacja

```
Biblioteka (index.html)
  → Książka (book.html?id=programista)
    → Spis treści
      → Rozdział (chapter.html?book=programista&id=1)
        → Historia → Słownik → Pytania → Zadania → Następny rozdział
```

## Uruchomienie

```bash
python3 -m http.server 8080
```

Otwórz http://localhost:8080

## Zawartość rozdziału

- opowiadanie ~350–600 słów + cliffhanger
- 3–5 dużych ilustracji między tekstem
- karty słów (PL → opcjonalnie UA)
- pytania z przykładową odpowiedzią (bez wpisywania)
- zróżnicowane zadania

## Książka 1

**Misja Programista** — Raspberry Pi 5 (czarna obudowa), 10 rozdziałów.

Pozostałe książki na półce: status „Wkrótce”.

## Stack

HTML + CSS + JavaScript (bez frameworków).
