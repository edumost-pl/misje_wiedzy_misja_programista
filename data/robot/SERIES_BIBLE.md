# MISJE WIEDZY — Misja Robot
# Biblia projektu (seria / książka 3)

Architektura jak w Misji Programista. Gatunek własny: **szkolny konkurs + drużyna + robotyka + legenda szkoły**.

---

## 1. Co to za książka

- **Gatunek:** przygoda + konkurs + praca zespołowa + robotyka + **legenda (nie mistyka)**.
- **Nie jest:** podręcznikiem AI, instrukcją montażu, rankingiem „kto najmądrzejszy”.
- **Silnik fabuły:** termin, rywale, odkrycia „Ooo…”, awaria, finał, **Nagroda Iskry**.
- **Dwa pytania serii:**
  1. Czy zdążą skończyć Iskrę?
  2. **Co kryje legenda Nagrody Iskry?**
- **Wniosek finału:** technologia jest ważna; ważniejsi są ludzie — i robot traktowany jak partner.
- **Nagrody:** Alfa — 1. miejsce (szybkość). Drużyna Maksa — **Nagroda Iskry** (partnerstwo).

## 2. Bohaterowie

### Drużyna Maksa (rdzeń)
| Postać | Siła | Charakter / running gag |
|--------|------|-------------------------|
| **Max** | zbiera ludzi, pyta, mówi do Iskry | „No dalej, Iskra… Dasz radę.” / „Nie obrażaj się.” |
| **Lena** | design, wygląd | **Rysuje wszędzie** — serwetki, marginesy, pudełka, rękaw bluzy |
| **Kuba** | konstrukcja | „**To da się naprawić**.” (często po rozebraniu) |
| **Sara** | kod, logika | **Widzi błędy wszędzie** — „Tu brakuje przecinka.” |

### Iskra (bohater, nie „przedmiot”)
- W tekście: **Iskra**, nie „robot” (chyba że mówi obcy).
- Max rozmawia z nią od R1 — dziecko przeżywa los **bohatera**, nie projektu.
- Łuk Iskry: plastik → zasilanie → ruch → oczy → myślenie → test → awaria → naprawa → finał → nagroda.

### Pan Witek
- Stary nauczyciel techniki. Strzeże **Nagrody Iskry**.
- Wspomina pierwszą Iskrę absolwentów — **legenda z prawdą**, nie magia.

### Rywale (nie złoczyńcy)

## 3. Styl

Jak książka 1: krótkie akapity, dialog `—`, emocje przez działanie, `📓 NOTATNIK MAKSA`, `***MISJA N — UKOŃCZONA***`, cliffhanger.

**Moment odkrycia (co rozdział):**
- Max: „**Ooo…** — Tutaj coś jeszcze jest / było / będzie.”
- Przykłady: bateria niepodłączona (R2), folia na obiektywie (R4).

Running joke: skarpetka max. 1× / 2–3 rozdz.; Kuba rozkręca coś „na chwilę”.

## 6. Legenda Iskry

- Absolwenci lat temu zbudowali robota **Iskrę** — nie najszybszego, lecz najbardziej współpracującego z ludźmi.
- **Nagroda Iskry** co roku — za traktowanie robota jak **partnera**, nie mebla.
- Max nazywa robota Iskrą **nie wiedząc** o legendzie → połączenie na finał.
- **Nie mistyka** — pamięć szkoły i wartość współpracy.
