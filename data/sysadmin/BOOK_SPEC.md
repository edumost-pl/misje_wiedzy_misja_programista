# BOOK_SPEC — Місія Адміністратор

## Формат

`format: "nonfiction"` — науково-популярна книга (DK / Usborne / No Starch Press), **не** художня.

Мова: українська. Вік: 10–12 років.

## Чого НЕМАЄ

- story / сюжет / герой / діалоги  
- MISJA UKOŃCZONA / mission  
- tasks як ігрові місії  
- questions як окремий «кінець художньої глави» у старому сенсі  

## Структура книги

1. Обкладинка  
2. Передмова  
3. Як користуватися книгою  
4. Зміст (частини + розділи)  
5. Частини 1–6 → розділи 1–22  
6. Словник  
7. Предметний покажчик  

## Одна таємниця = один розділ

Кожен `chapterXX.js` розкриває **одне** головне запитання.  
Теми наступних розділів — лише коротка інтрига, без пояснення.  
Повне пояснення microSD як носія ОС / Imager / boot — **лише в розділі 3**.  
Урок термінала (pwd/ls/clear) — **лише в розділі 6**.  
SSH — **лише в 16**; Minecraft Server як практика — **лише в 18–20**.  

### Старт розділу (обов’язково)

1. Життєва ситуація («У мене теж таке було!»)  
2. Запитання  
3. Припущення дитини  
4. Пояснення + аналогія  
5. Лише потім команда Linux  
6. Практика‑дослідження  
7. Висновок  

**Заборонено** починати з визначення, терміна чи команди (`find`, `SSH`, `IP`…).  
**Заборонено** вводити команду як «X — це команда, яка…» без попередньої життєвої загадки.  
**Перевірка:** без команд Linux текст усе одно цікавий? Якщо ні — переписати.

## Схема `chapterXX.js`

```js
{
  id, bookId, part, partTitle, title,
  learn: string[],          // 📌 Що ти дізнаєшся
  content: Block[],         // основний текст + інтерактив
  remember: string[],       // 📌 Запам'ятай
  commands: [{cmd, does}],  // таблиця команд
  glossary: [{term, def}],  // нові слова
  check: CheckItem[],       // ✅ Перевір себе (4–5: core + optional)
  next: number | null
}
```

### Block types

| type | Призначення |
|------|-------------|
| `text` | Абзац (markdown: **жирний**, `код`) |
| `ul` | Маркований список (`items: string[]`) |
| `h2` | Підзаголовок блоку |
| `image` | Ілюстрація + prompt |
| `think` | 🤔 Питання в тексті (варіанти, без миттєвої відповіді) |
| `reveal` | Відповідь на think через кілька абзаців |
| `fact` | 💡 Цікавий факт (`text` + опційно `items`) |
| `diary` | 📒 Щоденник адміністратора |
| `draw` | ✏ Намалюй / підпиши |
| `errors` | ⚠ Типові помилки (рядок або `{title, myth, truth}`) |
| `project` | Мініпроєкт |
| `code` / `terminal` | Блок термінала (формат нижче) |
| `nanowindow` | Інтерактивна схема вікна nano (`file`, `body`, `modified`, `status`) |
| `try` | Спробуй зараз / дослідження (`body`, опційно `checklist`, `footer`) |
| `callout` | Виноска DK (`title`, `text`, опційно `variant`: `note`/`tip`/`warning`, `point`) |
| `wow` | «✨ Це дивовижно!» — емоційний факт (`title`, `text`) |
| `diagram` | Схема/інфографіка (`title`, `layout`: `stack`/`flow`/`compare`, `items[]`, `caption`) |
| `spread` | DK-розворот: текст + hero (`layout`: `hero-right`/`hero-left`/`hero-full`, `kicker`, `title`, `lead`, `body`, `hero`, `callouts[]`, `supporting[]`, `foot`) |

### Формат термінала (частина 2+)

Запрошення на Raspberry Pi OS: **`pi@raspberrypi:~$`** (не `user@linux` / `root@ubuntu`).  
Домашній шлях у прикладах: **`/home/pi`**.

```
# Коментар українською
pi@raspberrypi:~$ команда

# Приклад відповіді
вихід системи
```

- Коментарі (`# …`) — українською  
- Команди — англійською (`pwd`, `ls`, `cd`…)  
- Рендер підсвічує: коментар / запрошення / команду / вихід  

### Check types

`mc` · `tf` · `fill` · `draw` · `whatif` · `match` · `error` · `explain`

Кожен елемент `check[]` має поля `hint` і `explanation`.  
Опційно `optional: true` — бонусне питання «за бажанням» (не іспит).  
Норма на розділ: **3 core + 2 optional** (розділи 1–3 і 21–22: **2+2**).

### Рендер «Перевір себе»

1. **Лише питання** — без ✓; мітки «обов’язково» / «бонус»  
2. **`<details>` 💡 Підказки** — спрямовують, не розкривають повністю  
3. **`<details>` ✅ Відповіді** — правильна відповідь + пояснення 1–3 речення

### Читання без Pi / разом із дорослим

- Блоки `fact` і футер `try` підтримують читання **без Pi** (щоденник, уява).  
- `book.frontMatter.withAdult` і `withoutPi` — на обкладинці книги.  
- **`data/sysadmin/class-without-pi.js`** — методичний трек B: у кожному розділі рендериться **«У класі без Pi»** (`renderClassWithoutPi` у `script.js`). Поля: `outcome`, `checklist[]`.
